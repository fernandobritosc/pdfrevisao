ESTRATÉGIA CONCURSOS
CONCEITOS BÁSICOS
●
Navegador Web (Web Browser)
◦
Software cliente responsável por disponibilizar diversas ferramentas para acesso
aos serviços oferecidos na internet
◦
Ferramenta utilizada para a visualização ou consumo de conteúdo web
●
Web
◦
WWW (World Wide Web)
▪Sistema de informações que interliga documentos hipermídia por meio de
hiperlinks
●
Servidores Web
◦
Computadores especializados no fornecimento de páginas web
●
HTTP (HyperText Transfer Protocol)
◦
Protocolo de transferência de hipertexto
◦
É o protocolo padrão para transferência de páginas web
●
Hipermídia
◦
Documentos em forma de hipertextos, imagens, sons e/ou vídeos
●
Hipertextos
◦
Textos cujo acesso se dá por meio de ligações digitais denominadas hiperlinks
●
HTML (Hyper Text Markup Language)
◦
Linguagem de Marcação de Hipertexto
◦
É o formato padrão de uma página web
●
Hiperlinks
◦
Referências dentro de um hipertexto para esse ou outro hipertexto
●
Arquitetura cliente/servidor
◦
Computadores ou softwares que consomem serviços (chamados de clientes) e
computadores ou softwares que fornecem serviços (chamados de servidores)
●
Recurso
◦
É qualquer documento, arquivo ou dispositivo endereçável
●
URL (Uniform Resource Locator)
◦
É o endereço virtual de um recurso em uma rede
●
Estrutura de uma URL
●
DNS (Domain Name System)
◦
É um protocolo cliente/servidor que traduz, transforma, resolv
Endereço IP e vice-versa
◦
Apresenta uma estrutura hierárquica e distribuída
●
FTP (File Transfer Protocol)
◦
Protocolo para transferência de arquivos

FUNCIONALIDADES COMUNS
●
Página Inicial
◦
Atalho
▪
Alt + HOME
◦
É a página aberta por padrão na inicialização de um navegador
◦
Em alguns navegadores é possível configurar mais de uma página como Página Inicial.
●
Navegação Privativa
◦
Evita que o navegador armazene informações de navegação sobre as sites e
páginas visitadas
◦
Também pode ser chamada de navegação anônima
◦
Não torna o usuário anônimo na internet
▪
O provedor de acesso ainda poderá rastrear as páginas visitadas
◦
Atalhos

▪

▪
Internet Explorer

▪
Microsoft Edge

●
Barra de Favoritos
◦
Apresenta atalhos para as páginas preferidas do usuário
◦
Na maioria dos navegadores, para exibir ou adicionar uma página como favorita, deve-
se procurar por uma estrela
●
Também são funcionalidades comuns
◦
Barra de Guias/Abas
◦
Gerenciamento de downloads (Ctrl+J)
◦
Histórico de navegação (Ctrl+H)
◦
Impressão de páginas (Ctrl+P)
◦
Modo Tela Cheia (F11)
◦
Bloqueador de Pop-up
◦
Proteção contra rastreamento (e Do Not Track)
◦
Plug-ins, Extensões e Complementos
◦
Filtro Antimalware
●
Cache
◦
Recurso para armazenamento temporário e local no disco rígido de cópias
de partes de páginas web, imagens e outros documentos
◦
Objetivo
▪
Exibir uma página web mais rapidamente
●
Cookies
◦
Pequenos arquivos de texto que armazenam informações básicas sobre o
visitante de um site
◦
Ex: nome, idioma, carrinho de compra, lista de produtos etc
◦
Cookies de Sessão
▪
Armazenados em memória
▪
Existem somente enquanto a sessão estiver ativa
▪
Não têm data de validade
◦
Cookies Persistentes
▪
Armazenados no disco rígido
▪
Persistem mesmo após encerrada a sessão
▪
Têm data de validade
◦
Funções
▪
Funções técnicas
●Controlam o tráfego do site, identificam os usuários e suas sessões
de uso, armazenam conteúdos
▪
Personalização
●Ajustam o site de acordo com o idioma, tipo de navegador e a
configuração regional de onde está o usuário
▪
Monitoramento
●Acompanham e registram o comportamento do público para que
seja possível medir e analisar a atividade no site
▪
Publicidade
●Permitem administrar os espaços publicitários e exibir anúncios de
acordo com o perfil específico de cada usuário
