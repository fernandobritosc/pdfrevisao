Introdução aos Navegadores

Essência de Prova: Tanto o Microsoft Edge (atual) quanto o Google Chrome são baseados no projeto de código aberto Chromium e utilizam o motor de renderização Blink. Eles são essencialmente "primos" tecnológicos.
2

Microsoft Edge

Navegador padrão do Windows 10 e 11, criado para substituir definitivamente o antigo Internet Explorer. É rápido, seguro e, por ser baseado no Chromium, é totalmente compatível com as extensões da Chrome Web Store.

💡 Critério de prova
O ambiente de consulta da Web oferecido pelo Edge, ao ser aberto, é formado por janelas e guias.
⚠️ Não confunda
  • O browser não é formado por e-mail, Office nativo, ferramentas de captura de tela ou caixas de entrada.
  • O núcleo funcional é a janela do navegador e suas guias.

Compatibilidade e Fim de Suporte (ActiveX / Flash / IE11)

💡 Critério de prova
O Microsoft Edge não oferece suporte a controles ActiveX. Quando aplicativos web exigirem ActiveX, BHOs ou Java, o caminho oficial é continuar usando o Internet Explorer 11, não o Edge.
⚠️ Adobe Flash e compatibilidades legadas
  • Adobe Flash: não é mais suportado desde 2020.
  • Não existe suporte nativo a Flash no Edge/Chrome modernos.
  • Recursos legados como ActiveX/BHOs não funcionam no Edge por padrão.
⚡ Pegadinha
Bancas confundem Edge com browser universal: ele não roda ActiveX e não suporta Flash. Para esses casos, o caminho é o IE11.

Configuração por URL

💡 Dica de Acesso Rápido
No Edge, é possível acessar as configurações diretamente pela barra de endereços (Omnibox) digitando o endereço:
edge://settings/

Gerenciador de Senhas

O Edge possui um gerenciador de senhas robusto. Além de salvar e preencher formulários com segurança, ele se destaca pelo recurso Monitor de Senhas.

⚠️ Atenção (Monitor de Senhas)
O Monitor de Senhas do Edge verifica proativamente e notifica o usuário se suas credenciais salvas forem encontradas em vazamentos de dados na Dark Web ou na internet, sugerindo a troca imediata.

⚡ Pegadinha de Banca (FCC/Cebraspe)
A navegação sem deixar rastros (não salva histórico, cookies, nem dados de formulário no PC local) no Edge é chamada de InPrivate. As bancas tentarão confundir com o termo "Guia Anônima" que é do Chrome, ou "Navegação Privativa" do Firefox. Lembre-se: O atalho (CTRL + SHIFT + N) é o mesmo do Chrome.

Limpeza de Dados e Performance

💡 Critério de prova
Quando um site está lento, uma alternativa segura é usar Limpar dados de navegação para excluir apenas cookies e cache daquele site. Isso pode melhorar o desempenho sem fechar abas ou desativar segurança.
⚠️ Não confunda
  • Modo de Alta Performance: não existe como função nativa no Edge.
  • Desativar firewall: compromete a segurança do sistema.
  • Fechar todas as abas: resolve performance, mas viola o enunciado quando ele pede algo que não afete outros sites.
  • Limpar todos os dados: pode causar problemas em outros sites salvos.
2.1

Leitura em Voz Alta (Read Aloud)

💡 Critério de prova
O Microsoft Edge, em sua versão mais atual, disponibiliza o recurso Ler em Voz Alta, que faz a leitura do texto de uma página da Web em voz audível, por meio da ferramenta Leitura Avançada / Immersive Reader.
⚠️ Características importantes
  • Lê o texto da página de forma audível.
  • Apresenta uma barra de ferramentas com controles de áudio.
  • Permite alterar a voz do leitor e ajustar a velocidade de leitura.
  • Permite pular para o parágrafo seguinte ou anterior.
⚡ Pegadinha
A banca pode confundir com "modo leitura" ou "imprimir página". O diferencial do Read Aloud é a saída de áudio do texto, não apenas formatação visual.
3

Google Chrome

Navegador desenvolvido pelo Google, líder mundial de mercado. Destaca-se pela alta integração com o ecossistema Google e velocidade de processamento.


Chrome Sync & Sandbox

🔒
SANDBOX
Sandbox = CAIXA DE AREIA (Isolamento de Processos)
  • Chrome Sync: Permite sincronizar favoritos, histórico, senhas, extensões e configurações entre computadores, tablets e smartphones vinculados à mesma Conta Google.
  • Sandbox (Isolamento): Arquitetura de segurança essencial. O Chrome executa cada aba (guia) ou extensão como um processo independente no sistema operacional. Se uma guia travar ou sofrer ataque de malware, as demais abas não são afetadas.

Configuração por URL

Comandos práticos na barra de endereço (Omnibox do Chrome):

  • chrome://settings/ - Abre a página de configurações.
  • chrome://downloads/ - Abre o gerenciador de downloads.
  • chrome://history/ - Abre o histórico de navegação.
  • chrome://flags/ - Acessa recursos experimentais e ocultos para desenvolvedores.

Acessibilidade e Legendas

💡 Caminho de prova
Para alterar o estilo das legendas de vídeos no Chrome, o caminho correto é: Mais (⋮) > Configurações > Avançado > Acessibilidade > Legendas.
⚠️ Caminhos errados comuns
  • Mais > Avançado > Acessibilidade > Legendas: errado, falta passar por Configurações primeiro.
  • Mais > Complementos > Acessibilidade > Legendas: errado, Complementos não é o menu correto.
  • Mais > Mais Ferramentas > Acessibilidade > Legendas: errado, não existe esse caminho.
⚡ Pegadinha
Bancas trocam intencionalmente o menu intermediário. Decore: Configurações > Avançado > Acessibilidade > Legendas é o caminho completo.

💡 Caminho de prova
Para que o Chrome reabra as mesmas abas/janelas da última sessão: Configurações > Inicialização > Continuar de onde você parou.
⚠️ Não confunda com reset
  • Restaurar configurações padrão não fica em Inicialização; o caminho é Configurações > Avançado > Redefinir e limpar > Restaurar configurações para os padrões originais.
  • Restaurar dados de navegação também não é uma opção de Inicialização no Chrome.
  • Configurações de conteúdo não é o nome correto do menu.
⚡ Pegadinha
A banca troca conscientemente itens de menus de configuração. Decore: no Chrome, Continuar de onde você parou é a opção de restaurar a sessão anterior; reset padrão fica em Redefinir e limpar.

Gerenciador de Senhas

Integrado à Conta Google. Possui a ferramenta Verificação de Segurança que varre as senhas salvas em busca de vazamentos de dados públicos, senhas fracas ou senhas repetidas em sites diferentes.


Segurança e Integridade da Página

💡 Critério de prova
Para verificar se está acessando uma versão mais segura e íntegra da página, o caminho direto é: URL começando com https:// e presença do cadeado ao lado da barra de endereços.
⚠️ O que NÃO serve para isso
  • Inspecionar elemento: é ferramenta de desenvolvimento, não garante integridade da conexão.
  • chrome://flags: são recursos experimentais, não servem para validar segurança do site.
  • Modo de segurança: não é uma opção/caminho oficial para essa verificação no Chrome.
  • Ícone de escudo: não é o indicador visual padrão de conexão segura.
⚡ Pegadinha
Bancas confundem: só o critério oficial (https:// + cadeado) corresponde à verificação de integridade/segurança da conexão no Chrome.

Perfis de Usuário

💡 Critério de prova
O Chrome permite utilizar diferentes perfis de usuário, separando informações como favoritos, histórico, senhas e configurações. Serve tanto para várias pessoas no mesmo computador quanto para separar contas diferentes do mesmo usuário, como pessoal e trabalho.
⚡ Pegadinha
Perfis não são o mesmo que janela anônima: perfis separam dados entre usuários/sessões; anônima apenas não salva rastros locais temporariamente.

Abrir link em nova guia e efeito no histórico

💡 Critério de prova
Ao clicar em um link com a tecla CTRL pressionada, a página é aberta em nova guia. Isso não altera o histórico da guia original, por isso o botão Voltar continua indisponível na aba inicial.
⚠️ Não confunda com
  • Modo anônimo: não deixa salvar histórico local, mas o botão Voltar funciona normalmente dentro da mesma guia.
  • Favoritos: não interferem no histórico de navegação.
  • Site seguro: não interfere no funcionamento do botão Voltar.

Configurações de Proxy

💡 Caminho de prova
Em Chrome (Windows), a abertura das configurações de proxy parte de: Configurações > Avançado > Sistema > Abrir configurações de proxy.
⚠️ Não confunda com
  • Privacidade e Segurança: não é essa a seção de proxy.
  • Ferramentas: não existe como menu raiz no Chrome.
  • Avançado > Sistema direto: no Chrome moderno, esse caminho é alcançado via Configurações primeiro.
  • Configurações > Avançado > Privacidade e Segurança > Configurações de proxy: incorreto, essa área não contém a entrada de proxy.
⚡ Pegadinha
Bancas trocam nomes de menus e ordem de passos. Decore: no Chrome, Configurações > Avançado > Sistema conduz à entrada de proxy.

⚠️ Confusões clássicas de banca
  • CTRL + T = nova guia, não reabrir guia fechada.
  • CTRL + SHIFT + T = reabrir guia fechada.
  • CTRL + W e CTRL + F4 = fechar guia atual.
  • As bancas trocam essas combinações para eliminar candidato.
🔥 Limites do modo anônimo/InPrivate
  • Não protege contra malware nem phishing.
  • Não impede provedor, administrador de rede ou empregador de ver a atividade.
  • Não garante anonimato total nem impede rastreamento por IP.
  • No Chrome, após fechar todas as janelas anônimas, são excluídos: histórico, cookies, dados de sites, informações de formulários e permissões concedidas.
⚡ Pegadinha Clássica (Gerenciador de Tarefas)
O Windows tem seu próprio Gerenciador de Tarefas (CTRL+SHIFT+ESC ou CTRL+ALT+DEL). Mas o Chrome possui o SEU PRÓPRIO gerenciador interno para verificar o consumo de memória de cada aba e finalizar abas travadas. O atalho interno do Chrome é SHIFT + ESC. As bancas adoram inverter!

Pontos Quentes de Prova (Revisão Rápida)

  • Atalhos Universais: CTRL+J (Downloads), CTRL+H (Histórico) e CTRL+SHIFT+DEL (Limpar Dados) funcionam de forma idêntica em ambos os navegadores.
  • Base Tecnológica: Tanto o Edge atual quanto o Chrome são baseados no código Chromium, logo, compartilham o mesmo motor e compatibilidade com extensões.
  • Navegação Oculta: O modo que não salva histórico local é InPrivate no Edge e Anônimo no Chrome (Atalho é o mesmo: CTRL + SHIFT + N).
  • Segurança do Chrome: A tecnologia Sandbox isola processos em guias independentes para garantir segurança e impedir que o travamento de uma aba derrube o navegador todo.
  • Abas Travadas: Para fechar uma aba travada no Chrome sem ter que fechar o navegador, usa-se o Gerenciador de Tarefas do Chrome através do atalho especial: SHIFT + ESC.
Q1

Questão Comentada – VUNESP

Essência da questão: Cai a distinção entre fechar aba e reabrir aba fechada no Google Chrome.
📌 Enunciado

No Google Chrome, versão 119, em sua configuração padrão, o atalho por teclado ______ fecha uma aba ativa dentro de uma janela, enquanto o atalho ______ permite reabrir a última aba fechada anteriormente na janela. Assinale a alternativa que preenche, correta e respectivamente, as lacunas do enunciado.

Alternativa Combinacao Status
A Ctrl + Alt + T ... Ctrl + T Incorreta
B Ctrl + Shift + Q ... Ctrl + Shift + N Incorreta
C Alt + F4 ... Alt + F2 Incorreta
D Ctrl + F4 ... Ctrl + T Incorreta
E Ctrl + W ... Ctrl + Shift + T Correta
⚡ Resolução comentada
  • Ctrl + W: fecha a guia atual.
  • Ctrl + Shift + T: reabre a última guia fechada, na ordem de fechamento.
  • As outras combinacoes apresentadas nao correspondem a essas funcoes no Chrome.
