Conceito de internet e evolução
Conceitos básicos de navegadores, web e os protocolos por trás da navegação (incidência ALTA)
Navegador Web (Web Browser)
É o software cliente responsável por disponibilizar diversas ferramentas para acesso aos serviços oferecidos na internet. As definições que já caíram em prova giram em torno do mesmo núcleo: é um programa/aplicativo/software; permite a interação dos usuários com páginas ou sites; e possibilita a navegação web na internet.

• "Aplicativo que disponibiliza ferramentas simples para acesso à internet"
• "Aplicativo que um usuário invoca para acessar e exibir uma página web"
• "Espécie de ponte entre usuário e conteúdo virtual na internet"
• Definição mais simples: ferramenta utilizada para a visualização ou consumo de conteúdo web

O verbo inglês To Browse significa "procurar" — que é o que mais fazemos na internet. Em 2018, o Chrome estava presente em 66,9% dos computadores pessoais, seguido do Firefox (11,4%) e do Internet Explorer (7,13%).
Arquitetura cliente/servidor
A internet funciona baseada na arquitetura cliente/servidor: computadores ou softwares que consomem serviços (clientes) e computadores ou softwares que fornecem serviços (servidores).

• Cliente web (navegador): faz uma requisição por uma página HTML ao servidor
• Servidor web: computador ou software especializado no fornecimento de páginas web; processa e retorna a resposta com a página solicitada
• Web (World Wide Web – WWW): sistema de informações que interliga documentos hipermídia por meio de hiperlinks
ConceitoDescrição
HipermídiaDocumentos em forma de hipertextos, imagens, sons e/ou vídeos
HipertextosTextos cujo acesso se dá por meio de ligações digitais denominadas hiperlinks
HiperlinksReferências dentro de um hipertexto para esse ou outro hipertexto
RecursoQualquer documento, arquivo ou dispositivo endereçável (página web, arquivo de multimídia, periférico etc.)
ℹ️
Exemplo prático (cliente/servidor): você acessa o site do Estratégia → consome conteúdo web; faz isso pelo navegador → usa um cliente web; a página tem hipertextos, vídeos, sons e imagens → é um documento hipermídia; esses conteúdos estão conectados → há hiperlinks.

Protocolos e linguagens da web

SiglaSignificadoPapel

HTTPSHyperText Transfer Protocol SecureImplementação do HTTP com mais segurança; ao acessar um site por HTTPS, é exibido um cadeado na barra de endereços

🧠 Bizu essencial
O navegador é sempre o CLIENTE — ele solicita a página ao servidor. Nunca o contrário.
🚨 Pegadinha da banca
O HTTP é protocolo de transferência de hipertexto, e não de hipermídia, porque em 1990 (época da sua criação) as páginas web só continham textos — imagens, sons e vídeos passaram a existir depois.

URL (Uniform Resource Locator)

A URL é o endereço virtual de um recurso em uma rede, oferecendo uma maneira uniforme e padronizada de localizar recursos na web. Ao digitar uma URL no navegador, ele localiza o recurso na internet e o recupera para o browser.

Estrutura básica: protocolo-ou-esquema://ip-ou-domínio:porta/caminho
Sintaxe completa: protocolo://nome-de-usuário@ip-ou-domínio:porta/caminho/recurso?query#fragmento
ComponenteDescrição
ProtocoloTambém chamado de esquema; protocolo utilizado para acessar o recurso
IP / DomínioNúmero de IP ou nome do domínio do servidor que hospeda o recurso (Host)
PortaPonto lógico que permite criar uma conexão em um processo (ex.: porta padrão do HTTPS é 443)
CaminhoEstrutura de diretórios dentro do servidor que armazena o recurso
RecursoComponente físico ou lógico disponível em um sistema computacional
Query / QueryStringPassa parâmetros adicionais ao servidor em formato chave-valor (iniciada por "?"; pares separados por "&")
Fragmento (âncora)Segue o caractere "#"; navega diretamente para uma seção específica de uma página. Não é enviado ao servidor — é processado exclusivamente pelo navegador
Nome de usuárioUsado em contextos que exigem autenticação para acessar recursos
Componentes obrigatórios × opcionais
• Obrigatórios: apenas Protocolo e Domínio
• Comuns, mas opcionais: Porta, Caminho e Recurso
• Raros, opcionais (sintaxe completa): Query, Fragmento e Nome de Usuário

Parâmetros UTM (padrão do Google para rastrear campanhas no Google Analytics): utm_source (origem de tráfego), utm_medium (meio/tipo de tráfego — ex.: cpc = anúncio pago), utm_campaign (nome da campanha), utm_term (palavras-chave), utm_content (versão do anúncio).
🚨 Pegadinha da banca
URL ≠ domínio. Se você muda o nome do recurso de Aula1.pdf para Aula2.pdf, a URL muda, mas o domínio permanece o mesmo. Exemplo resolvido: https://www.estrategiaconcursos.com.br/app/dashboard/cursos/aulas/aula1.pdf → protocolo https, domínio estrategiaconcursos.com.br (o www é só um prefixo que pode ser omitido), porta 443 (omitida), caminho /app/dashboard/cursos/aulas, recurso aula1.pdf.

DNS e domínios

O DNS (Domain Name System) é um protocolo cliente/servidor que traduz, transforma, resolve um Nome/Domínio em um Endereço IP e vice-versa, com estrutura hierárquica e distribuída. O espaço de nomes é um conjunto organizado de possíveis nomes — os nomes devem ser exclusivos, assim como os endereços IP.

• ICANN: entidade que controla o registro e a manutenção de domínios em nível global (define que .br pertence ao Brasil, .pt a Portugal, .jp ao Japão, .es à Espanha)
• Registro.br: entidade responsável pelo registro e manutenção de domínios brasileiros
• Subcategorias .br: .com.br (atividade comercial) e .org.br (organização não-governamental sem fins lucrativos); algumas categorias exigem comprovação documental
🚨 Pegadinha da banca
Um site .br está registrado no Brasil — isso não significa que ele esteja hospedado fisicamente no Brasil.

Internet Explorer, Mozilla Firefox, Google Chrome, Microsoft Edge, Opera, Safari, Shiira, Konqueror — sendo os quatro primeiros os campeões de questões de prova. Eles são atualizados quase todo mês (na década de 2010-2019 foram lançadas 78 versões do Chrome — quase oito por ano).

A maioria das bancas considera Barra de Navegação, Barra de Endereço e Barra de Pesquisa como três elementos diferentes; outras consideram todos como Barra de Navegação. Além disso, todos os navegadores permitem realizar buscas diretamente na barra de endereço, sem necessidade de barra de pesquisa separada.

Ao posicionar o cursor do mouse sobre um link, o cursor vira uma mãozinha e a Barra de Status surge exibindo o endereço do link — isso indica que aquele local é um link.
⚠️
Iconografia: para exibir ou adicionar uma página como favorita, procure o ícone de estrela ao lado direito da barra de endereço (estrela cheia = página já é favorita). O ícone da casinha retorna à página inicial; o cadeado indica acesso seguro via HTTPS.

Abas, favoritos, histórico e downloads
Funcionalidades comuns de navegação e gerenciamento

Abas (guias)

A Barra de Guias/Abas fornece a capacidade de alternar entre diferentes páginas web em uma única instância do browser. A quantidade máxima de abas abertas depende do recurso computacional disponível, passando de cinquenta com facilidade.

• Fixar guia: clicar com o botão direito na guia → Fixar Guia. As guias fixadas ficam à esquerda, com tamanho reduzido. O Internet Explorer é o único dos quatro grandes que NÃO possui esse recurso
• Versões recentes do Mozilla Firefox chamam as abas/guias de separador
Agrupamento de abas
Permite organizar e agrupar abas abertas, facilitando o gerenciamento de múltiplas abas. Passos: clicar com o botão direito em uma guia → "Adicionar Guia ao Novo Grupo" → dar nome/rótulo e escolher uma cor (ou adicionar a um grupo já existente). É possível desagrupar ou fechar todas, e "sanfonar" o grupo (aberto/fechado).

• Google Chrome: adicionado na versão 88 (janeiro de 2021)
• Microsoft Edge: adotado a partir da versão 92 (2021)
• Mozilla Firefox e Internet Explorer: NÃO possuem o recurso nativamente (Firefox removeu; oferece a extensão "Tab Groups")
🚨 Pegadinha da banca
Ao organizar muitas guias para acessar diariamente (ex.: webmails e bancos), o recurso usado no Chrome é o agrupamento de guias — não fixar guias, pois guias fixadas ficam pequenas e à esquerda da barra de guias.

No modo de navegação anônima, os arquivos baixados e os favoritos criados são mantidos após o fechamento das janelas — só o histórico, cookies e dados de formulários não são salvos.

Página inicial e impressão

• Página Inicial (ALTA): página aberta ao clicar no ícone da casinha. Chrome e Edge diferenciam página inicial (ícone da casinha; só é possível configurar uma página) de página de inicialização (exibida ao abrir o navegador; é possível configurar várias páginas, cada uma em uma nova guia). Atalho: ALT+HOME
• Impressão (média): todos os navegadores permitem imprimir páginas web — trechos específicos, páginas individuais (vírgula ou ponto-e-vírgula) ou intervalo (hífen). Atalho: CTRL+P (P de Print). O Internet Explorer só permite imprimir uma única página ou um único intervalo
• Modo Tela Cheia (baixa): F11 — o site ocupa todo o monitor, sem botões, menus ou barras
🧠 Bizu essencial
CTRL+D = favorito · CTRL+H = Histórico · CTRL+J = downloads (J de Jail/downloads) · CTRL+P = Print (imprimir) · CTRL+F = Find (localizar) · CTRL+T = Tab (nova guia) · CTRL+W = fecha guia

Cookies, cache, sessões e privacidade
Temas de incidência Altíssima — os mais cobrados em prova

Cookies (incidência Altíssima)

Cookies são pequenos arquivos de texto capazes de armazenar informações básicas sobre o visitante de um site: nome, idioma, estado de autenticação, registros de navegação, carrinho de compra, lista de produtos etc. São enviados por servidores web ao visitante e armazenados em uma pasta local no computador do usuário para melhorar a experiência de navegação.

Ficam armazenados até perderem a validade (minutos ou anos). Em acessos futuros, o navegador recupera as informações do cookie e as reenvia ao site, aplicando automaticamente as configurações salvas (ex.: escolher o idioma uma vez e não precisar escolher de novo). Cada página tem seu próprio cookie — um site similar não acessa os dados do cookie de outro site.

🚨 Pegadinha da banca
Cookies não são spam nem vírus e não conseguem capturar dados do computador — só coletam informações de navegação. O usuário pode bloqueá-los ou personalizar a lista de sites que podem usá-los; esse bloqueio pode impedir que algumas páginas sejam exibidas corretamente.
🚨 Pegadinha da banca
Na navegação anônima são utilizados cookies de sessão: a página continua instalando cookies, mas tudo é deletado ao fechar o navegador.

Cache (incidência Altíssima)

Ao navegar na internet, os navegadores armazenam temporariamente no computador imagens e partes de sites visitados para acelerar a navegação, carregando as páginas mais rapidamente — isso é o Cache (Web Cache). Em vez de pedir ao servidor para preparar e enviar outra página, o navegador envia uma cópia de uma versão já em cache.

• Web Cache: recurso de armazenamento temporário e local no disco rígido de cópias de páginas web, imagens e outros documentos, com o objetivo de exibir a página mais rapidamente
• Memória Cache: dispositivo de acesso que opera mais rápido que a Memória RAM — não tem nada a ver com Web Cache
CACHECOOKIES

Conteúdo armazenado apenas no computador clienteConteúdo armazenado no computador cliente e no servidor
Geralmente expira manualmenteGeralmente expira automaticamente
Consome grande espaço de armazenamentoConsome menos espaço de armazenamento

🚨 Pegadinha da banca
Para apagar as imagens e partes de sites que aceleram o carregamento, limpe o dado de navegação denominado CACHE — e não cookies, favoritos ou dados de formulário.

Navegação privativa (incidência Altíssima)

Em navegação normal, o navegador guarda informações para facilitar a vida do usuário: histórico de páginas visitadas, buscas realizadas, informações de formulários (nome, endereço, telefone, CPF). Em computadores compartilhados, o recomendável é a navegação privativa — também chamada de navegação anônima (Chrome) ou InPrivate (Edge/IE).

Ao término da navegação, são removidas do computador as informações sobre a navegação realizada: histórico de navegação e de pesquisas, cookies, dados de formulários. Não salva senhas, não mantém informações inseridas em formulários e não salva permissões concedidas a sites.

❌

📌
Navegação anônima — o que ela NÃO faz
📌 Aprendizado
→ Keylogger: variação de spyware capaz de capturar e armazenar as teclas digitadas no teclado; geralmente obtido por downloads de sites suspeitos ou anexos de e-mail — a navegação anônima não impede keyloggers nem qualquer outro malware (quem protege é o antivírus)
→ A atividade ainda pode ficar visível para: os sites visitados (incluindo anúncios e recursos deles), sites em que fizer login, empregador/escola/quem administra a rede utilizada, provedor de acesso à internet e mecanismos de pesquisa
→ Um serviço web pode ver o seu endereço IP (identifica o local geral) e a sua identidade, se você fizer login

→ ⚠️ Cuidado: o modo anônimo impede apenas que o navegador salve a atividade no histórico local do dispositivo — não remove arquivos baixados ao ser encerrado e não garante proteção contra vírus e worms.

Plug-ins, extensões e complementos

• Plug-ins: programas ou componentes externos instalados no navegador que permitem utilizar recursos não disponíveis nativamente (multimídia, tipos especiais de conteúdo). Ex.: Adobe Flash Player (vídeos/jogos), Plugin do Java (Internet Banking). São arquivos executáveis externos, praticamente não utilizados atualmente
• Extensões: pequenos programas integrados à lógica de aplicação do navegador, que adicionam novos recursos e personalizam a experiência. Instalam-se do próprio navegador (não há download de outro local)
• Complementos (ou Add-On), no Firefox: conjunto de Extensões + Temas + Plug-ins. Temas alteram a aparência do navegador (botões, imagem de fundo)
📌
Extensões × complementos — visão das bancas
📌 Aprendizado
→ Extensões são um tipo de complemento e permitem, entre outros recursos, a integração do Firefox com alguns sítios da Internet
→ Complementos personalizam o Firefox com estilos ou recursos extras (temas, botões, funções adicionais)

→ ⚠️ Cuidado: a CESPE já tratou plug-in, complemento, extensão e add-on como sinônimos — programa baixado da Internet que adiciona uma função ao aplicativo (recurso que ele não teria nativamente). Não estranhe se a banca usar os termos como equivalentes.
ℹ️
Proteção contra rastreamento e Do Not Track (DNT): a Proteção contra Rastreamento ajuda a evitar que informações sobre a sua navegação sejam enviadas a provedores de conteúdo terceirizados, limitando o que esses terceiros coletam. O Do Not Track (DNT) é um mecanismo passivo que solicita ao site não rastrear — alguns sites respeitam, a maioria não. Todos os navegadores possuem "Não Rastrear"; todos, exceto o Google Chrome, possuem Proteção contra Rastreamento nativa (no Chrome é preciso extensão). O Firefox bloqueia por padrão rastreadores de mídias sociais, cookies de rastreamento entre sites, criptomineradores e fingerprinters.
🚨 Pegadinha da banca
Pop-ups não são vírus — são pequenas janelas que se abrem sobre a janela principal, geralmente com anúncios. O bloqueador de pop-up impede que essas janelas apareçam, oferecendo mais controle; hoje já vem habilitado por padrão nos navegadores.
📌
Configuração de cookies no Firefox
Em Privacidade e Segurança → Cookies e Dados de sites, o Firefox informa o espaço em disco utilizado pelos cookies, dados de sites e cache (ex.: "Seus cookies, dados de sites e cache armazenados estão atualmente usando X MB do espaço em disco") e oferece a opção "Apagar cookies e dados de sites quando o Firefox for fechado".

→ ⚠️ Cuidado: o texto da opção é "quando o Firefox for fechado" — não existe "apagar cookies quando o Firefox for aberto"; a limpeza ocorre ao encerrar o navegador.
5
Segurança na navegação e atalhos úteis
Filtros antimalware, phishing, sandbox, sincronização e tabela de atalhos (incidência Altíssima)

Filtro Antimalware

Todos os navegadores possuem um recurso que ajuda a detectar sites de phishing e proteger contra download e instalação de malwares. A proteção ocorre de três maneiras:

1) Durante a navegação, analisa páginas em busca de características suspeitas → exibe mensagem sugerindo cautela
2) Compara os sites visitados com uma lista dinâmica de sites de phishing e mal-intencionados → exibe aviso de site bloqueado
3) Verifica os arquivos baixados contra listas de softwares mal-intencionados → avisa que o download foi bloqueado

No Internet Explorer e MS-Edge, o filtro se chama Filtro SmartScreen — verifica os downloads comparando com uma lista de arquivos conhecidos e funciona indiretamente como gerenciador de downloads, bloqueando os arriscados.
📌
Navegação Segura do Chrome — níveis de proteção
📌 Aprendizado
→ A Navegação Segura do Chrome exibe avisos que ajudam na proteção contra malware, sites e extensões abusivos, phishing, anúncios maliciosos e invasivos e ataques de engenharia social
→ Níveis de proteção oferecidos (apenas três): proteção reforçada, proteção padrão e sem proteção

→ ⚠️ Cuidado: nomenclaturas como "proteção avançada", "extra" ou "básica" não existem nos níveis atuais do Chrome — não caia em listas com esses rótulos.
XSS (Cross-Site Scripting)
Navegadores ajudam a evitar ataques maliciosos por vulnerabilidades de páginas web, como o Cross-Site Scripting (XSS). Ataques desse tipo visam o código (script) de uma página executado no navegador do usuário, ao invés de no servidor — é uma tentativa de inserir scripts maliciosos no navegador. A maioria tem como objetivo coletar dados pessoais, redirecionar vítimas para sites controlados pelo atacante ou fazer o computador executar operações comandadas pelo atacante. Os navegadores buscam identificar e bloquear a inicialização desses scripts automaticamente.
🚨 Pegadinha da banca
Phishing é um tipo de golpe/ataque (sites falsos que imitam sites reais para roubar dados, ex.: www.bb.com.br × www.bb.net.br), não é o nome da funcionalidade de proteção — o recurso que combate isso é o filtro antimalware/antiphishing. A extensão de domínio também é indício de mensagem forjada (ex.: ONU usa .org, não .com).

Sandbox (Google Chrome)

O Sandbox é um recurso para melhorar a segurança do navegador. No Chrome, cada guia/página aberta é um processo separado e independente (monitorados separadamente pelo SO). Se uma guia travar, o navegador e as outras guias não são afetados. O Sandbox fornece uma camada de proteção isolada para cada processo: se uma página maliciosa for aberta, o código malicioso fica contido no Sandbox e não afeta outras guias nem o computador.

Todas as páginas exibidas são verificadas pelo Sandbox, e alguns plugins também são integrados a ele — mas um plugin instalado fora da caixa de areia pode acessar recursos sensíveis do computador. O Google Chrome foi o primeiro navegador a implementar o Sandbox; depois Firefox e Internet Explorer também o fizeram.

Perfis de usuário no Chrome
📌 Aprendizado
→ O Google Chrome permite utilizar diferentes perfis de usuário, mantendo todas as informações do navegador separadas: favoritos, histórico, senhas e outras configurações

Software nativo × multiplataforma
📌 Aprendizado
→ Software nativo: desenvolvido para rodar diretamente em uma plataforma específica — comumente já vem instalado com o sistema operacional ao qual pertence, sem compatibilidade nativa com outros sistemas
→ O Firefox é código livre e multiplataforma: roda em Windows, Linux, Android, macOS etc. — não é software nativo do Linux

→ ⚠️ Cuidado: dizer que um navegador é "nativo do Linux" e que por isso "não pode ser executado no Windows" está errado — os navegadores consagrados são todos multiplataforma.

🚨 Pegadinha da banca
O texto de um link não reflete, necessariamente, a URL que será aberta — o texto exibido pode ser qualquer nome (ex.: link com texto "Vasco" abrindo www.flamengo.com.br). Por isso, um link com texto HTTPS não garante que o site aberto seja seguro.

Servidor proxy

O servidor proxy age como intermediário entre o computador e a Internet: intercepta todas as solicitações à Internet e verifica se cada requisição pode ser atendida diretamente do seu cache. É usado para aumentar o desempenho, filtrar requisições e ocultar o computador na internet, aumentando a segurança.

• Permite realizar cache de páginas web e restringir o acesso a determinados conteúdos (o administrador da rede pode liberar apenas os sites considerados convenientes)
• Servidores proxy geralmente são parte de firewalls corporativos
• O Firefox permite configurar o proxy pelo próprio usuário nas opções de rede — não exige softwares de terceiros
📌
DHCP, Intranet, SMTP e certificado digital
DHCP (Dynamic Host Configuration Protocol) permite a atribuição automática de endereços IP: um servidor especial distribui endereços IP aos hosts que solicitam conexão, dispensando a configuração manual — é aplicável em intranets (rede interna)

Intranet = rede privada de acesso restrito que usa os mesmos padrões e protocolos da Internet (http, tcp, ip, smtp, pop3); mesmo sem acesso à Internet, é possível utilizar todos os seus recursos

SMTP (Simple Mail Transfer Protocol) é usado exclusivamente para transmissão de e-mails — ferramentas de pesquisa (Google, Bing) usam HTTP/HTTPS, não SMTP

Certificado digital = documento eletrônico emitido por uma Autoridade Certificadora que vincula uma entidade a uma chave pública; obrigatório para assinatura digital. Em regra é armazenado no próprio navegador — instalá-lo no sistema operacional não é obrigatório e não dispensa a autenticação de usuários, o controle de acesso e as configurações de rede
